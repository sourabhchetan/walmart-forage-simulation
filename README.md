# Tasks Completed

## Task 1 — Advanced Data Structures

### Objective

Implement a novel **Power-of-Two Max Heap** data structure in Java for Walmart’s shipping department.

### Concepts Used

* Heap Data Structure
* Java Collections
* Algorithm Optimization
* Time Complexity Analysis
* Dynamic Branching Factor

### Features

* Configurable heap branching factor
* Efficient insert operation
* Efficient pop-max operation
* Generalized k-ary heap implementation

### Technologies

* Java

---

## Task 2 — Software Architecture

### Objective

Design a UML class diagram for a dynamically configurable data processor supporting multiple modes and database integrations.

### Concepts Used

* UML Class Diagrams
* SOLID Principles
* Strategy Pattern
* Dependency Injection
* Software Design Patterns

### Features

* Configurable processing modes
* Swappable database connectors
* Extendable architecture

* PlantUML

## Task 3 — Relational Database Design

### Objective

Design a normalized relational database schema for Walmart’s pet department.

### Concepts Used

* Database Normalization
* Primary & Foreign Keys
* Relational Database Modeling

### Features

* Product management
* Customer transactions

* Manufacturer relationships
* Animal-product relationships

* DBML
